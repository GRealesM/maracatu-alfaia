// Maracatu alfaia grooves: the shared library for the practice page.
// One line per bar, 16 sixteenths, one character each. Spaces are ignored.
//   R L  full stroke, right or left hand
//   r l  ghost note, right or left hand
//   ~    rumble     B  both hands     F  flam     .  rest
// End a line with x2, x3... to repeat the bar, and with > text to add a note to it.
// A line starting with # starts a new groove. Lines starting with // are comments.
// A groove with an error is skipped and named in a warning on the page.
// While this file has no grooves, the page behaves as a full editor.

# Baque de parada - Baque + 3
R..R lR.R lR.R L.R.  > One parada
L... .... .... ....  > Here we do a 360 turn to the left during silence
R..R lR.R lR.R L.R.  > Second parada
L... .... .... ....  > Now to the right...
R..R lR.R lR.R L.R.  > Third parada
L.R. L.R. .R.r L.R.  > and we flow to transition
R... lR.. lR.. lR..  x3  > Three arrastos and back to the start

# Baque Martelo (intro) - Baque + 4 + "go back"
R... .... .... .RLR
R... .... .... .R..
R... .... .... ....  > We loop here until Newton whistles with the same pattern below, then we move to bar 4
R.R. R.R. .R.R l...  > And after this, we go straight to martelo

# Baque de Afoxé - Baque + Waves
R..R l... .R.R l...  > Afoxe
R..R l... .R.R lR.R  > Afoxe with a twist into the next bar
l..R l... .R.R l...  > another afoxe after the twist
R.R. R.R. R... ....  > At the end we yell "HEY!" and start again

# Baque Aú - Baque + punch upwards
R.R. R.R. .R.R .RLR  > 4 hits + 2 hits + pradiddle
R..R L..R L..R L...
R.R. R.R. .R.R .RLR  > Again 4 + 2 + pradiddle
R..R .R.. R..R .RLR
..R. L.R. lR.. lR..  > Luanda transition
R..R LR.R LR.R L.R.  > Parada
L... BRRR ...R L...  > Resolution and we flow into afoxé (we DO NOT loop)
