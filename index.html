    Notation guide

    One line per bar, 16 sixteenths, one character each. Spaces are ignored, so group them by beat. A line starting with # starts a new groove and gives its name.

    # Example groove
R..L R.r. .L.l R.R.  > main groove
R..L R.r. .L.l R.R.  x3
~~~~ ~~~~ B... F...  > roll into the break
    R Lright or left hand, full stroke
    r lright or left hand, ghost note
    ~rumble (roll)
    Bboth hands together
    Fflam: soft left grace note just before a right stroke
    .rest

    x2, x3… after the bar repeats it. A note for the bar goes at the end after >. On a repeated bar the note shows on the first repeat only.

    Apply text in “This groove” replaces the current groove. In “All grooves”, grooves are matched by name: the same name updates it, a new name adds a groove. Apply never deletes. Lines starting with // are comments.
